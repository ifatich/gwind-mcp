01 Fondasi

4 pilar utama Gwind

Gwind bukan satu library monolitik, melainkan gabungan empat elemen independen yang saling melengkapi — semuanya publik, tidak ada ketergantungan ke package private @pegadaian.

// 01 OTOMASI

gwind-system-ui CLI

Package publik npm yang men-generate source code komponen ke proyek lokal. Perintah init menyiapkan fondasi CSS, add meng-copy komponen spesifik dari registry.

// 02 STANDAR

gwind-v2 (Design Tokens)

Package npm (versi 0.2.1) yang mengekspor variabel CSS murni: 11 palette warna, 12 skala tipografi, spacing gw-2 s.d. gw-120, radius, shadow, dan breakpoint — kompatibel Micro Frontend.

// 03 INTERAKSI

Reka UI (Headless Primitives)

Library headless component Vue 3 yang menyediakan aksesibilitas dan logika interaksi (dialog, dropdown, combobox, popover) — tanpa styling bawaan, sepenuhnya dikontrol oleh Gwind.

// 04 KECEPATAN

Tailwind CSS v4

Utility-first CSS framework engine Oxide. Integrasi native dengan gwind-v2 melalui @theme, animasi @utility animate-*, dan source scanning tanpa konfigurasi PostCSS.

03 Fitur Anti-Bocor

CSS Isolation — 5 Lapis Pertahanan

Untuk aplikasi Micro Frontend (Module Federation), Gwind menjamin nol kebocoran CSS antar host dan remote. Arsitektur 5-layer ini sudah diverifikasi di @originjs/vite-plugin-federation.

01

Scope <div> Unik

Setiap view terbungkus scope selector turunan dari package.json → gw-scope-*. Placeholder .gw-scope di-replace saat build.

02

postcss-prefix-selector

Plugin PostCSS otomatis menambahkan prefix scope class ke setiap selector CSS, menjamin tidak ada rule global yang bocor.

03

tailwindcss-mangle

Utility class Tailwind di-hash/di-mangle sehingga nama class antar remote tidak mungkin bentrok.

04

Vue <style scoped>

Isolasi per komponen Vue 3 dengan data-v-* attribute selector — komponen A tidak bisa menyentuh komponen B.

05

@layer gw-base

Cascade layer CSS memastikan aturan fondasi Gwind tidak bisa ditimpa secara tidak sengaja oleh kode di layer lain.

06 Konvensi Tim

Do's & Don'ts

Patuhi konvensi ini agar konsistensi desain tetap terjaga di seluruh remote app. Setiap aturan sudah diverifikasi di Gwind Skill Module v1.7.0.

✓

Yang Harus Dilakukan

4 aturan wajib
1
Semantic token dulu, palette belakangan
bg-primary text-foreground border-border
2
Semua state komponen wajib terdefinisi
default hover active focus-visible disabled loading
3
Bahasa Indonesia untuk semua label pengguna
Simpan Batal Lanjutkan
4
Import dari family barrel lokal
import { Button } from '@/components/ui/button'
✗

Yang Dilarang

3 pantangan
1
Kode hex mentah atau piksel arbitrer
#FF5733 17px — mapping ke token Gwind
2
Override paksa: !important & inline style
style="color:red" !important
3
Package private @pegadaian — sudah deprecated
@pegadaian/gwind-vue @pegadaian/gwind-ui
