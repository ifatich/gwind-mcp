01 Fondasi

Core Capabilities Skill Module

Skill ini dirancang untuk tidak sekadar menulis kode secara acak. AI akan secara presisi mengorkestrasi 4 pilar fundamental Gwind Design System di setiap task yang dikerjakan.

// 01 READINESS CHECK

Membaca layer, property, dan variables Figma langsung dari canvas. Nilai-nilai ini otomatis di-map ke token resmi gwind-v2, atau dicatat sebagai Token Gap jika belum terdefinisi.

// 03 CODE GEN

Vue 3 Code Generator

Merakit komponen gwind-system-ui (termasuk state management dari Reka UI) menjadi file Vue SFC yang utuh. Skill juga memastikan teks label mematuhi standarisasi Bahasa Indonesia.

// 04 ISOLATION

CSS Isolation Enforcer

Memastikan setiap komponen Vue yang di-generate terbungkus class isolation. Skill secara ketat menerapkan arsitektur 5-layer untuk mencegah kebocoran styling di environment Micro Frontend (RemoteApp).

06 Fitur Anti-Bocor

CSS Isolation — 5 Layers of Defense

Pada arsitektur Micro Frontend (Module Federation), Gwind menjamin nol kebocoran CSS antar host dan remote app. Setiap kali skill men-generate kode, 5 layer isolasi ini akan langsung diterapkan secara otomatis.

01

Unique Scope Wrapper <div>

Setiap view akan dibungkus oleh div dengan class scope unik (diambil dari package.json → gw-scope-*). Placeholder .gw-scope akan di-replace otomatis saat proses build.

02

postcss-prefix-selector

PostCSS plugin yang otomatis menambahkan prefix class scope ke setiap selector CSS, memastikan tidak ada global style yang bocor ke luar remote app.

03

tailwindcss-mangle

Melakukan obfuscation/mangling pada utility class Tailwind sehingga nama class antar remote app tidak akan pernah bentrok.

04

Vue <style scoped>

Isolasi bawaan Vue 3 menggunakan attribute selector data-v-* untuk memastikan style di Komponen A tidak mempengaruhi Komponen B.

05

@layer gw-base

Memanfaatkan CSS Cascade Layers untuk mengamankan aturan dasar Gwind agar tidak tertimpa secara tidak sengaja oleh global style eksternal.

09 Coding Conventions

Do's & Don'ts

Aturan wajib untuk menjaga konsistensi desain di seluruh remote app. Asisten AI diprogram secara ketat melalui instruksi skill untuk menegakkan aturan ini saat men-generate kode dari Figma MCP.

✓

Yang Harus Dilakukan (Do's)

4 Aturan Wajib
1
Utamakan Semantic Token, Hindari Direct Palette
bg-primary text-foreground border-border
2
Semua state komponen wajib terdefinisi
default hover active focus-visible disabled loading
3
Gunakan Bahasa Indonesia untuk User-facing Label
Simpan Batal Lanjutkan
4
Import dari Local Component Path
import { Button } from '@/components/ui/button'
✗

Yang Harus Dihindari (Don'ts)

3 Larangan Utama
1
Menggunakan Raw HEX Color atau Arbitrary Pixel
#FF5733 17px — mapping ke token Gwind
2
Override Paksa Menggunakan !important atau Inline Style
style="color:red" !important
3
Menggunakan Deprecated Package @pegadaian/*
@pegadaian/gwind-vue @pegadaian/gwind-ui
