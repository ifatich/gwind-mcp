01 Fondasi

Kapabilitas Inti Skill Module

Skill ini dirancang untuk tidak sekadar menulis kode secara acak, melainkan secara presisi mengorkestrasi empat elemen fundamental dari Gwind Design System di setiap tugas yang ia kerjakan.

// 01 PENGECEKAN

Environment Readiness Check

Sebelum satu baris kode pun ditulis, skill menjalankan 9 langkah pengecekan krusial: memverifikasi instalasi gwind.json, eksistensi token gwind-v2, utilitas gwindTwMerge, hingga pengaturan PostCSS.

// 02 INSPEKSI

Figma-to-Token Engine

Membaca layer, property, dan variabel Figma langsung dari kanvas. Nilai ini kemudian dipetakan secara akurat ke token resmi gwind-v2, atau dicatat sebagai Token Gap jika tidak tersedia.

// 03 IMPLEMENTASI

Vue 3 Code Generator

Merakit komponen gwind-system-ui (termasuk logika state Reka UI) menjadi Vue SFC yang utuh. Skill juga memastikan label teks mematuhi aturan standar komponen Berbahasa Indonesia.

// 04 KEAMANAN

CSS Isolation Enforcer

Memastikan setiap komponen Vue yang dihasilkan selalu terbungkus dengan class isolasi. Skill menegakkan arsitektur 5-lapis untuk mencegah kebocoran styling di Micro Frontend (Remote App).

05 Skenario 2

Mode Audit — Review & Fix

Komponen lama sudah ada tapi tidak sesuai Figma. Skill menjalankan 5 fase audit sistematis: re-inspeksi Figma MCP, klasifikasi gap, perbaiki via token, dan laporan terstruktur.

P1

Figma Baseline — Re-inspeksi per Komponen

Setiap komponen dalam scope di-inspeksi ulang dari Figma MCP. Jangan gunakan data inspeksi lama — selalu re-run sebelum audit dimulai.

Figma MCP — Komponen: Badge
fill: color/success→bg-success (expect: Badge variant=green)
color: color/success-foreground→text-success-foreground
padding: 2px 8px→size=sm (built-in prop)
P2

Audit Table — Klasifikasi Setiap Property

Setiap property dimasukkan ke tabel dengan status: ✅ match, ⚠️ close, 🔧 fixable, ❌ mismatch. Token gap didokumentasikan sebelum perbaikan dimulai.

06 Fitur Anti-Bocor

CSS Isolation — 5 Lapis Pertahanan

Untuk aplikasi Micro Frontend (Module Federation), Gwind menjamin nol kebocoran CSS antar host dan remote. Setiap kali skill meng-generate kode dari Figma MCP, layer isolasi ini otomatis diterapkan pada komponen Vue Anda.

01

Scope <div> Unik

Setiap view terbungkus scope selector turunan dari package.json → gw-scope-*. Placeholder .gw-scope di-replace saat build.

02

postcss-prefix-selector

Plugin PostCSS otomatis menambahkan prefix scope class ke setiap selector CSS, menjamin tidak ada rule global yang bocor.

03

tailwindcss-mangle

Utility class Tailwind di-hash/di-mangle sehingga nama class antar remote tidak mungkin bentrok.

04

Vue <style scoped>

Isolasi per komponen Vue 3 dengan data-v-* attribute selector — komponen A tidak bisa menyentuh komponen B.

05

@layer gw-base

Cascade layer CSS memastikan aturan fondasi Gwind tidak bisa ditimpa secara tidak sengaja oleh kode di layer lain.

09 Konvensi Tim

Do's & Don'ts

Konvensi wajib untuk menjaga konsistensi desain di seluruh remote app. Asisten AI telah diprogram secara ketat lewat instruksi skill untuk selalu menegakkan aturan ini setiap kali menerjemahkan desain dari Figma MCP.

✓

Yang Harus Dilakukan

4 aturan wajib
1
Semantic token dulu, palette belakangan
bg-primary text-foreground border-border
2
Semua state komponen wajib terdefinisi
default hover active focus-visible disabled loading
3
Bahasa Indonesia untuk semua label pengguna
Simpan Batal Lanjutkan
4
Import dari family barrel lokal
import { Button } from '@/components/ui/button'
✗

Yang Dilarang

3 pantangan
1
Kode hex mentah atau piksel arbitrer
#FF5733 17px — mapping ke token Gwind
2
Override paksa: !important & inline style
style="color:red" !important
3
Package private @pegadaian — sudah deprecated
@pegadaian/gwind-vue @pegadaian/gwind-ui
